# CDS annotation code

The detailed CDS annotation and scoring implementation is withheld while the
paper is under review. It will be released in this directory after the paper is
accepted.

This temporary restriction covers the annotation prompt, scoring rubric
implementation, model-calling pipeline, and related processing scripts. The
public repository continues to provide the recommendation benchmark and LCDS
evaluation code for use with released CDS artifacts.

Full CDS artifacts will also be made available after paper acceptance. See
[`results/README.md`](results/README.md) for the expected artifact location.
